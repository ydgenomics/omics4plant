| `$$` | 当前 Shell 的进程 ID |

### 九、生物信息文件处理

#### BED 排序、区间长度筛选
```bash
sort -k1,1 -k2,2n file.bed                          # 按染色体、起始位点排序
awk '{if($3-$2>=1000) print}' file.bed               # 筛选长度≥1000区间
awk '{print $0 "\t" $3-$2}' file.bed                 # 增加一列长度
```

#### GTF 排序
```bash
sort -k1,1 -k4,4n file.gtf
```

#### FASTA 序列提取、多行转单行、短序列过滤
```bash
# 提取指定序列
samtools faidx ref.fa chr1:1000-2000

# 多行序列转单行(线性化)
awk '/^>/ {if(seq) print seq; print; seq=""} !/^>/ {seq=seq$0} END {print seq}' file.fa

# 过滤长度<100bp的序列
awk '/^>/ {name=$0; getline; if(length($0)>=100) print name"\n"$0}' file.fa
```

#### FASTQ 统计 read 数和平均长度
```bash
# read 数
wc -l file.fq | awk '{print $1/4}'
# 或
grep -c "^@" file.fq

# 平均长度
awk 'NR%4==2 {sum+=length($0); count++} END {print sum/count}' file.fq
```

#### VCF 去注释、筛选变异
```bash
grep -v "^#" file.vcf                           # 去除注释行
awk '$6>=30' file.vcf                           # 按QUAL值筛选
awk '$1=="chr1" && $2>=100000 && $2<=200000' file.vcf
```

#### SAM 按染色体和比对质量筛选
```bash
# MAPQ ≥ 30
awk '$5>=30' file.sam

# 提取比对到 chr1 的
awk '$3=="chr1"' file.sam

# 排除未比对的
awk '$3!="*"' file.sam

# 筛选正链比对
awk 'and($2,16)==0' file.sam
```

## 二、空间转录组基础

### 1. 核心原理
- 在组织切片上保留空间位置信息的前提下，捕获 mRNA 并进行测序
- 通过空间条形码（Spatial Barcode）将基因表达与组织坐标关联

### 2. 技术平台对比

| 技术 | 原理 | 分辨率 | 代表平台 |
|------|------|--------|----------|
| **原位捕获** | 载玻片上带有空间条形码的探针捕获 mRNA | 55μm（Visium）/ 纳米级（Stereo-seq） | 10x Visium、Stereo-seq |
| **原位测序/杂交** | 在组织原位直接测序或荧光杂交 | 亚细胞级 | MERFISH、seqFISH、ISS |

### 3. 提供的生物学信息
- 组织内基因表达的空间异质性
- 细胞类型在组织中的空间分布
- 细胞间通讯与微环境解析
- 发育过程中的空间动态变化
- 疾病（如肿瘤）的空间生态位

### 4. 空间域分析主流算法

| 算法 | 核心思想 | 特点 |
|------|----------|------|
| **BayesSpace** | 贝叶斯模型，结合空间近邻信息增强聚类 | 提高低分辨率数据的空间聚类 |
| **SpaGCN** | 图卷积网络，整合基因表达与空间坐标 | 可识别任意形状的空间域 |
| **stLearn** | 提取空间形态特征 + 表达归一化 | 含 SME 归一化方法 |
| **Giotto** | 多算法集成框架 | 支持 HMRF、spatial network 等 |
| **Scanpy (spatial)** | 结合空间邻居图进行聚类 | 通用性强，生态丰富 |

## 三、scRNA-seq 单细胞转录组

### 1. 核心概念

| 概念 | 定义 |
|------|------|
| **单细胞转录组** | 在单个细胞分辨率下检测全基因组范围的基因表达 |
| **唯一分子标识符 (UMI)** | 为每条初始转录本添加的唯一条形码，用于去除 PCR 重复，实现绝对定量 |
| **Dropout 事件** | 由于捕获效率低，某些基因在部分细胞中未检测到表达的现象 |
| **高变基因 (HVG)** | 在不同细胞间表达变异程度较大的基因，用于降维聚类 |
| **批次效应** | 因实验时间、操作者、试剂批次、测序平台等非生物学因素导致的系统性表达差异 |

### 2. 分析主要目标
- 细胞异质性解析：识别组织中的细胞亚群
- 细胞类型注释：基于标记基因或参考数据集鉴定细胞身份
- 发育轨迹推断：重建细胞分化或状态转变的连续过程
- 差异分析：比较不同条件/组别间的细胞组成和基因表达变化

### 3. 批次效应矫正方法

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| **CCA (Seurat)** | 典型相关分析，寻找共享相关结构 | 多样本整合 |
| **Harmony** | 迭代软聚类 + 线性校正 | 大规模图谱整合 |
| **Scanorama** | 互近邻搜索 + 全景拼接 | 多个数据集 |
| **MNN (Mutual Nearest Neighbors)** | 寻找互最近邻细胞，估计批次偏移 | 成对校正 |
| **BBKNN** | 批次平衡的 KNN 图构建 | 大样本量 |
| **ComBat** | 经验贝叶斯框架，估计批次效应参数 | 已知批次分组 |
| **LIGER** | 整合非负矩阵分解 (iNMF) | 跨物种、跨平台 |

### 4. 细胞聚类意义
- 发现新的细胞类型/状态
- 识别稀有细胞群体
- 为差异分析、拟时序分析提供细胞分组基础
- 揭示细胞异质性的层级结构

## 四、scATAC-seq 单细胞染色质可及性测序

### 1. 测序原理
- **Tn5 转座酶**携带测序接头，优先切割并插入到开放的染色质区域
- 开放的染色质区域被片段化并连接上接头，经 PCR 扩增后测序
- 测序 reads 在开放区域富集，形成"峰"（Peak）

### 2. Tn5 转座酶作用
- 识别开放的染色质区域
- 同时进行 DNA 片段化和接头连接（Tagmentation）
- 使文库构建高效且可在单细胞水平操作

### 3. Peak Calling 工具

| 工具 | 适用场景 |
|------|----------|
| **MACS2** | 最常用，适用于 ATAC-seq 和 ChIP-seq |
| **Genrich** | 专为 ATAC-seq 设计，可去除线粒体 reads |
| **HMMRATAC** | 基于半监督 HMM，适合单细胞 ATAC |
| **SnapATAC** | 自带 peak calling 的 scATAC 分析流程 |

### 4. 预处理流程
```
1. 去接头、低质量过滤（fastp/Trimmomatic）
2. 比对到参考基因组（Bowtie2/BWA）
3. 去除线粒体 reads
4. 去除 PCR 重复（Picard/samtools）
5. 过滤低质量细胞（TSS 富集分数、唯一 reads 数）
6. Peak calling（MACS2/Genrich）
7. 构建细胞 × Peak 矩阵
```

### 5. 下游分析内容
| 分析 | 内容 |
|------|------|
| 降维聚类 | 基于 peak 矩阵的细胞分群 |
| 差异可及性分析 | 鉴定不同细胞群的差异开放区域 |
| 转录因子足迹分析 | 预测调控该细胞群的转录因子（HINT-ATAC、TOBIAS） |
| Motif 富集分析 | 鉴定差异 peak 中富集的 TF 结合基序 |
| 基因活性评分 | 基于 gene body 附近的 peak 推测基因活性 |
| 多组学整合 | scATAC + scRNA 联合分析 |

## 七、RNA velocity 与拟时序分析

| 对比维度 | **RNA velocity** | **拟时序分析 (Pseudotime)** |
|----------|------------------|------------------------------|
| **核心原理** | 未剪接/已剪接 mRNA 比值推断转录动态变化的方向和速率 | 基于表达谱相似性将细胞排序到连续的轨迹上 |
| **推断内容** | 未来表达状态的变化方向（"转录推动力"） | 细胞在分化/发育路径上的相对位置 |
| **时间方向** | 明确的方向性（有向矢量） | 无向的连续过程排序（需设定起点） |
| **代表工具** | scVelo, Velocyto | Monocle, Slingshot, PAGA |
| **关联关系** | RNA velocity 可为拟时序分析提供方向性验证，或直接作为拟时序的"箭头指示" |
| **核心区别** | RNA velocity 基于**剪切动力学模型**，预测未来的状态变化；拟时序基于**表达相似性**，描述细胞在当前状态沿发育轨迹的排布 |

### 关联关系
- **互补验证**：RNA velocity 提供方向性推断，验证拟时序轨迹是否正确
- **组合使用**：在拟时序图上叠加 RNA velocity 箭头，增强轨迹解释
- **互为补充**：RNA velocity 揭示短期的转录动态，拟时序描述长期的发育进程

## 八、基础分析逻辑

### 1. 基因共表达网络 (WGCNA)
- 计算基因间的表达相关性（Pearson/Spearman）
- 幂函数加权使网络满足无标度拓扑
- 识别共表达模块（层次聚类 + 动态剪枝）
- 关联表型性状进行模块功能分析

### 2. 单细胞降维聚类
```
标准化 → 高变基因筛选 → PCA → 基于 PCA 的 KNN 图 → UMAP/t-SNE 可视化 → 社区检测聚类（Leiden/Louvain）
```

### 3. 低表达基因过滤
```python
# 过滤在少于3个细胞中表达的基因
sc.pp.filter_genes(adata, min_cells=3)
# 或按表达细胞比例过滤
sc.pp.filter_genes(adata, min_cells=int(0.01 * adata.n_obs))
```

### 4. 降维方法对比

| 方法 | 类型 | 特点 |
|------|------|------|
| **PCA** | 线性降维 | 保留全局结构，作为聚类输入 |
| **t-SNE** | 非线性降维 | 保留局部邻居关系，可视化效果好 |
| **UMAP** | 非线性降维 | 兼顾局部和全局结构，速度更快 |

## 十、空间聚类评估指标

| 指标 | 含义 | 公式/方法 |
|------|------|-----------|
| **轮廓系数 (Silhouette Score)** | 评估聚类紧密度与分离度 | 接近 1 表示聚类良好 |
| **ARI (调整兰德指数)** | 与已知标签的一致性 | 校正随机一致性 |
| **NMI (归一化互信息)** | 聚类与标签的互信息 | 0~1 之间，越接近 1 越好 |
| **Moran's I** | 空间自相关 | > 0 表示空间聚集 |
| **Geary's C** | 空间自相关 | < 1 表示空间聚集 |
| **空间连通性** | 聚类区域的空间连续性 | 区域内连通比例 |
| **CHAOS 指数** | 聚类的空间混杂程度 | 低值表示空间一致性高 |
| **PAS 分数** | 纯度与空间连续性的综合 | 针对空间数据的专有指标 |

## 十一、单细胞多组学科研课题完整设计思路

### 1. 经典课题框架

```
科学问题 → 实验设计 → 数据产生 → 数据处理 → 分析挖掘 → 实验验证 → 结论
```

### 2. 单细胞多组学课题设计模板

**阶段一：项目背景与科学假设**
- 选定疾病/发育过程/组织
- 明确研究空白（如某细胞类型的异质性未被揭示）
- 提出明确科学假设

**阶段二：实验设计**
- 样本选择：病例/对照，时间梯度，空间位置
- 组学组合：
  - scRNA-seq → 细胞图谱与异质性
  - scATAC-seq → 表观调控机制
  - 空间转录组 → 空间位置信息
  - 必要时加入 CITE-seq（蛋白）/ scTCR-scBCR（免疫组库）

**阶段三：数据预处理与质控**
- 各模态独立质控
- 批次效应评估与矫正
- 多模态样本对齐与匹配

**阶段四：单模态分析**
- scRNA：降维聚类 → 细胞注释 → 差异分析 → 拟时序
- scATAC：聚类 → 差异 peak → motif → 基因活性评分 → 调控网络
- 空间：空间聚类 → 空间差异 → 解卷积 → 空间通讯

**阶段五：多组学整合**
- WNN 分析（加权最近邻，Seurat v5）
- MOFA+（多组学因子分析）
- 跨模态标签转移与预测
- 基因表达与染色质可及性的关联

**阶段六：验证与深化**
- CRISPR 敲除/敲降验证关键调控因子
- 免疫组化/原位杂交验证空间分布
- 独立队列验证
- 功能性实验（类器官、报告基因等）

### 3. 课题设计要点总结

| 要素 | 关键考虑 |
|------|----------|
| 样本量 | 足够的生物学重复（建议 ≥ 3） |
| 时间点 | 发育/疾病进程中 3-5 个关键时间点 |
| 分组 | 实验组与对照组明确 |
| 多组学整合 | 同一批样本或匹配样本，增加一致性 |
| 验证策略 | 计算预测 + 实验验证，确保结论可靠 |
| 创新性 | 新细胞类型、新调控机制、空间微环境解析 |
