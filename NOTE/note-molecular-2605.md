# 正链基因 vs 负链基因：复制与转录的区别

## 一、核心区别总结

| 特征 | 正链基因 (+) | 负链基因 (-) |
|------|-------------|-------------|
| **染色体方向** | 5' → 3' | 5' → 3' |
| **基因方向** | 与染色体一致 | 与染色体相反 |
| **转录方向** | 5' → 3' (从左到右) | 5' ← 3' (从右到左) |
| **TSS位置** | 基因的 start (5'端) | 基因的 end (5'端) |
| **模板链** | 负链 (-) | 正链 (+) |

## 二、复制 vs 转录的区别

### 复制 (Replication)

| 特征 | 复制 (所有基因) |
|------|----------------|
| **目的** | 复制整个基因组 |
| **产物** | DNA → DNA |
| **聚合酶** | DNA聚合酶 |
| **模板** | 两条链都作为模板 |
| **起始点** | 复制原点 (Ori) |
| **方向性** | 双向复制 (双向) |
| **是否需要引物** | 需要 RNA 引物 |
| **保真度** | 高 (有校对功能) |
| **细胞周期** | S 期 |

### 转录 (Transcription)

| 特征 | 转录 (针对基因) |
|------|----------------|
| **目的** | 表达特定基因 |
| **产物** | DNA → RNA |
| **聚合酶** | RNA聚合酶 |
| **模板** | 仅一条链 (模板链) |
| **起始点** | 启动子 (Promoter) |
| **方向性** | 单方向 (5'→3') |
| **是否需要引物** | 不需要 |
| **保真度** | 较低 (无校对) |
| **细胞周期** | 整个细胞周期 |

## 三、正链基因 vs 负链基因的转录差异

### 正链基因 (+)

```text
染色体: 5' ==============================> 3'
位置:   1                              1000
        |                               |
        + 基因                          |
方向:   5' ---------> 3'                |
        |                               |
TSS:    start (5' 端) = 100            |
        |                               |
模板链: 负链 (-)                         |
        |                               |
RNA:    5' -----> 3' (从左到右)          |
```

**具体过程**：
```
负链模板: 3' <----------------------- 5'
              ↑ 读取方向 (3'→5')
              
正链编码: 5' -----------------------> 3'
              ↑ 序列相同

RNA 产物: 5' -----------------------> 3'
```

### 负链基因 (-)

```text
染色体: 5' ==============================> 3'
位置:   1                              1000
        |                               |
        - 基因 (方向相反)                |
        <------------- 3'   5'          |
        |                               |
TSS:    end (5' 端) = 1000             |
             |                          |
模板链: 正链 (+)                         |
        |                               |
RNA:    5' <----- 3' (从右到左)          |
```

**具体过程**：
```
正链模板: 3' <----------------------- 5'
              ↑ 读取方向 (3'→5')
              
负链编码: 5' -----------------------> 3'
              ↑ 序列相同

RNA 产物: 5' -----------------------> 3'
        (序列与负链相同，但方向从右到左)
```

## 四、复制在正负链基因中的差异

### 复制叉方向

```text
复制原点 (Ori)
     |
     ▼
     
正链作为模板时:
正链模板: 3' -----------------------> 5'
新链合成: 5' -----------------------> 3' (前导链)

负链作为模板时:
负链模板: 5' -----------------------> 3'
新链合成: 3' -----------------------> 5' (后随链，冈崎片段)

注意：虽然合成方向看起来不同，但实际都是 5'→3'
```

### 复制与转录的方向冲突

```text
正链基因 (+):
复制方向: 5' ---> 3' (同向)
转录方向: 5' ---> 3' (同向)
结果: 无冲突 ✓

负链基因 (-):
复制方向: 5' ---> 3' (向右)
转录方向: 5' <--- 3' (向左)
结果: 可能冲突 (头对头) ⚠️
```

## 五、实际示例

### 正链基因示例 (BRCA1)

```r
# 正链基因
gene: BRCA1
chromosome: 17
strand: +
start: 43,044,294
end: 43,125,482
TSS: 43,044,294 (start)

转录时:
- 模板链: 负链 (NC_000017.11 的互补链)
- 读取方向: 43,125,482 → 43,044,294 (从右向左)
- RNA合成: 43,044,294 → 43,125,482 (从左向右)
- RNA序列: 与正链相同 (T→U)
```

### 负链基因示例 (TP53)

```r
# 负链基因？TP53 实际上在正链
# 举个负链例子：某个基因
gene: EXAMPLE
chromosome: 1
strand: -
start: 500,000
end: 501,000
TSS: 501,000 (end)

转录时:
- 模板链: 正链
- 读取方向: 500,000 → 501,000 (从左向右？等等)
- 正确: 读取方向 500,000 → 501,000? 不对

更正:
负链基因的转录:
模板链 (正链): 3' <------------------ 5'
读取方向:       500,000 ← 501,000 (从右向左)
RNA合成:        500,000 → 501,000 (从左向右？不对)

实际上:
模板链正链: 5' ---基因--- 3'
          500,000      501,000
读取方向:   3'→5' 需要模板链反向
所以聚合酶从 501,000 向 500,000 移动
RNA 从 5'→3' 合成，但这是从右向左
所以 RNA 的 5' 端在 501,000 (TSS)
```

## 六、关键要点

### 1. 转录的通用规则
- **永远是新链 5'→3' 合成**
- **永远是模板链 3'→5' 读取**
- **TSS 永远是新链的 5' 端**

### 2. 正链基因 (+)
- TSS = 基因的 **start** (最左)
- 转录方向：左 → 右
- 模板链：负链
- 编码链：正链

### 3. 负链基因 (-)
- TSS = 基因的 **end** (最右)
- 转录方向：右 → 左
- 模板链：正链
- 编码链：负链

### 4. 复制 vs 转录

| 对比项 | 复制 | 转录 |
|-------|------|------|
| 范围 | 全基因组 | 单基因 |
| 模板 | 双链 | 单链 |
| 起始 | 复制原点 | 启动子 |
| 产物 | DNA | RNA |
| 引物 | 需要 | 不需要 |
| 校对 | 有 | 无 |

## 七、记忆口诀

```
正链基因像阅读，
从左向右把书读。
Start 就是 TSS 处，
模板负链不含糊。

负链基因反向走，
从右向左记心头。
End 是 TSS 的位，
模板正链是助手。

复制转录虽不同，
新链合成 5'→3'。
模板读取 3'→5'，
方向相反记心中。
```

# 分子生物学核心知识简明整理

## 一、中心法则

```
DNA → RNA → 蛋白质
(转录)  (翻译)
```

## 二、DNA相关

**结构**：
- 双螺旋：两条链反向平行（5'→3' 和 3'→5'）
- 碱基配对：A-T（2氢键），G-C（3氢键，更稳定）

**重要概念**：
- **基因**：编码蛋白质或功能RNA的DNA片段
- **基因组坐标**：永远 5'→3' 递增
- **正链（+）**：转录方向与坐标一致（5'→3'）
- **负链（-）**：转录方向与坐标相反（3'←5'）

## 三、RNA相关

### 转录过程
```
DNA模板链 3' → 5'（被读取）
RNA新链   5' → 3'（合成方向）
```

### RNA类型
| 类型 | 功能 |
|------|------|
| mRNA | 蛋白质模板 |
| tRNA | 转运氨基酸 |
| rRNA | 核糖体组成 |
| snRNA | RNA剪接 |
| lncRNA | 调控基因表达 |

### mRNA结构
```
5'帽 → 5'UTR → CDS（编码区）→ 3'UTR → polyA尾
         ↑         ↑           ↑
       TSS     起始密码子    终止密码子
```

**关键位点**：
- **TSS**：转录起始位点，可在多个位置
- **5'UTR**：不编码蛋白，调控翻译
- **CDS**：编码蛋白的序列
- **3'UTR**：调控mRNA稳定性

## 四、转录本（Transcript）

### 从DNA到成熟mRNA
```
DNA（基因）
  ↓ 转录
Pre-mRNA（含内含子和外显子）
  ↓ 剪接（去除内含子）
成熟mRNA（仅外显子）
  ↓ 翻译
蛋白质
```

### 选择性剪接
```
一个基因 → 多个转录本 → 多种蛋白质

示例：基因有外显子1,2,3,4
- 转录本A: 1-2-3-4
- 转录本B: 1-2-4（跳过3）
- 转录本C: 1-3-4（跳过2）
```

## 五、基因区域

```
[---启动子---][---5'UTR---][---外显子1---][---内含子---][---外显子2---][---3'UTR---]
     ↑            ↑              ↑                           ↑              ↑
  调控序列      TSS起点        CDS起始                    CDS终止        polyA信号
```

## 六、链方向与坐标

### 正链基因（+）
```
染色体: 5' ================ 3'
坐标:   1                  1000
基因:   100  (TSS)     900
        Start          End
```

### 负链基因（-）
```
染色体: 5' ================ 3'
坐标:   1                  1000
基因:   900             100 (TSS)
        Start           End
注意：尽管Start < End，但转录方向相反
```

## 七、关键术语速查

| 术语 | 解释 |
|------|------|
| **TSS** | 转录起始位点，RNA合成开始的位置 |
| **Start codon** | 起始密码子（ATG），翻译开始 |
| **Stop codon** | 终止密码子（TAA/TAG/TGA），翻译结束 |
| **UTR** | 非翻译区，不编码蛋白 |
| **Intron** | 内含子，剪接去除 |
| **Exon** | 外显子，保留在成熟mRNA中 |
| **Splicing** | 剪接，去除内含子连接外显子 |
| **Isoform** | 异构体，同一基因的不同转录本 |

## 八、记忆要点

### 方向规则
1. **DNA合成**：5'→3'
2. **RNA合成**：5'→3'
3. **蛋白质合成**：N端→C端
4. **模板读取**：3'→5'

### 坐标规则
1. 基因组坐标永远 5'→3' 递增
2. 正链：Start = TSS (近似)
3. 负链：End = TSS (精确)

### 一个基因的复杂性
- 有多个TSS（不同启动子）
- 有多个转录本（选择性剪接）
- 有多个polyA位点
- 产生多种蛋白质异构体

## 九、实际应用（SCENIC+）

```python
# 基因注释需要的列
gene_annotation = {
    'Chromosome': 'chr1',
    'Start': 100,        # 基因区域开始
    'End': 1000,         # 基因区域结束
    'Strand': '+',
    'Gene': 'GENE_A',
    'Transcription_Start_Site': 150,  # TSS位置
}

# 启动子区域（用于调控分析）
promoter = {
    'start': TSS - 1000,
    'end': TSS + 100,
}
```

## 十、常见误区

❌ **错误**：负链基因的Start > End  
✅ **正确**：负链也是Start < End，但转录方向相反

❌ **错误**：一个基因只有一个TSS  
✅ **正确**：一个基因可以有多个TSS

❌ **错误**：所有转录本都编码蛋白  
✅ **正确**：有些是非编码RNA（lncRNA、miRNA等）

❌ **错误**：剪接只发生在mRNA  
✅ **正确**：tRNA、rRNA也需要加工

---

**一句话总结**：DNA存储信息，RNA传递信息（经过剪接加工），蛋白质执行功能。基因结构复杂，可产生多种产物。
