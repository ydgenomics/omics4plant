# Cellular Deconvolution

空间转录组（空转，ST）与单细胞转录组（单细胞，scRNA-seq）的反卷积，是指利用单细胞数据的高分辨率细胞类型定义，去解析空间转录组中每个空间位点（Spot/Voxel）内混合了哪些细胞类型及其比例的技术。
相比于传统的 Bulk RNA-seq 反卷积，空转反卷积具有更明确的空间位置约束，是目前空间组学分析的核心步骤。

## 为什么空间转录组需要反卷积？
目前主流的空间转录组技术（如 10x Genomics Visium）由于分辨率限制，其空间 Spot（直径约 55 微米）并不是单细胞级别的：

* 多细胞混合：每个 Spot 内部通常包含 1 到 10 个甚至更多的细胞。
* 信号混杂：Spot 测得的基因表达量是内部所有细胞的“平均值”。
* 反卷积的目的：将这个“平均值”拆解，恢复每个 Spot 在空间位置上的精确细胞成分。

------------------------------
## 核心工作原理
空转反卷积的核心逻辑是：以单细胞数据为“基因字典”，去翻译空间位点的“混合文本”。

   1. 构建参考矩阵：从同组织或同疾病的单细胞数据中，提取出各类已知细胞（如 T细胞、肿瘤细胞、成纤维细胞）的标志性表达谱。
   2. 空间映射与计算：通过统计学、机器学习或深度学习算法，计算空间每个 Spot 的基因表达特征最符合哪些细胞类型的组合。
   3. 输出空间概率/比例：得到一个矩阵，明确指出 Spot A 包含 60% 肿瘤细胞 + 40% T细胞，而临近的 Spot B 包含 100% 巨噬细胞。

------------------------------
## 主流空转反卷积工具
根据算法原理的不同，目前主流的工具可以分为以下几类：
## 1. 基于概率建模 / 贝叶斯框架（高精度、主流）

* Cell2location：目前公认最稳健的工具之一。基于贝叶斯层次模型，能有效处理空间数据中的负二项噪声，对微量、稀有细胞的检测能力极强。
* RCTD (Robust Cell Type Deconvolution)：速度快，针对测序平台间的批次效应进行了专门的监督学习优化，适合大规模数据集。
* Stereoscope：基于概率模型，直接使用单细胞和空转的原始计数（Counts）进行建模。

## 2. 基于非负最小二乘 / 线性回归（速度快、轻量）

* Seurat (TransferData)：经典的单细胞分析包自带功能，使用锚定点（Anchors）机制进行预测评分映射，简单易用。
* SPOTlight：结合了非负矩阵分解（NMF）和非负最小二乘（NNLS），运行速度非常快。

## 3. 基于深度学习 / 最优传输（适合跨平台）

* STDeconvolve：无需单细胞参考的无监督反卷积工具（利用类似文本挖掘的LDA模型），在没有匹配单细胞数据时非常有用。
* Tangram：利用空间组和单细胞数据的基因表达相关性，通过深度学习将单细胞直接“塞入”空间 Spot 中，甚至能实现亚细胞级别的预测。

------------------------------
## 分析的标准工作流程（Workflow）

   1. 数据准备：
   * 空间转录组数据（带空间坐标的 Expression Matrix）。
      * 配对/相近组织来源的单细胞转录组数据（必须包含清晰的细胞类型注释）。
   2. 基因整合与批次校正：找出两套数据集的共有基因，并校正由于不同测序技术带来的批次效应。
   3. 运行反卷积算法：输入两个矩阵，计算细胞比例。
   4. 空间可视化（Spatial Plot）：在组织切片图上，以饼图、散点权重图或热图的形式，展示特定细胞（如免疫细胞）在空间上的浸润和分布。
