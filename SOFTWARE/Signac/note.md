## scATAC-seq 核心概念详解

### 1. 基础概念解释

#### **Fragment（片段）**
- **定义**：在Tn5转座酶切割后，从开放染色质区域释放出来的DNA片段
- **特点**：
  - 每个fragment代表一个**单个细胞**中**单个开放染色质区域**
  - 通常长度在50-1000bp之间
  - 包含两端序列信息（可用于识别插入位点）

#### **Peak（峰）**
- **定义**：在基因组上reads/fragments显著富集的区域
- **特点**：
  - 代表**潜在的开放染色质区域**（如启动子、增强子）
  - 由多个fragments堆积形成
  - 通常宽度为200-500bp

#### **Fraction（分数/比例）**
- **定义**：各种统计指标的比例值
- **常见fraction指标**：
  - **FRiP**：Fraction of Reads in Peaks（peak区的fragments比例）
  - **Fraction of mitochondrial reads**：线粒体reads比例（质控指标）
  - **Fraction of promoter reads**：启动子区reads比例

### 2. Call Peak（峰值识别）的意义

#### **为什么需要call peaks？**

1. **识别开放染色质区域**
   ```r
   # 将连续的fragments信号转化为离散的功能元件
   fragments → peak calling → 开放染色质区域列表
   ```

2. **降维和特征选择**
   - 从全基因组（~30亿碱基）降维到~10-20万个peak区域
   - 提高计算效率和数据可解释性

3. **生物学意义**
   - **启动子peaks** → 基因表达调控
   - **增强子peaks** → 远程调控元件
   - **CTCF peaks** → 染色质边界
   - **细胞特异性peaks** → 细胞身份和功能

4. **细胞异质性分析**
   ```r
   # 构建peak-by-cell矩阵
   peaks × cells matrix → 聚类分析 → 识别不同细胞类型
   ```

### 3. Coverage Plot（覆盖度图）解读

#### **什么是Coverage Plot？**
显示特定基因组区域上fragments的堆积程度，类似山峦起伏的图形。

#### **如何解读Coverage Plot？**

```text
   Peak区域
    ▲
    |    /\      /\      /\  
    |   /  \    /  \    /  \    ← 覆盖度高的区域（信号峰）
    |  /    \  /    \  /    \
    | /      \/      \/      \
    |__________________________→ 基因组坐标
     基因A    基因B    基因C
```

**关键解读要素：**

1. **峰的高度** → 染色质开放程度
   - 越高 → 该区域越开放
   - 越低 → 染色质越紧密

2. **峰的宽度** → 开放区域大小
   - 窄峰（~200bp）→ 典型的转录因子结合位点
   - 宽峰（>500bp）→ 增强子或启动子区域

3. **峰的分布** → 调控模式
   ```r
   # 示例：不同基因的调控模式
   - TSS附近窄峰 → 基因活跃表达
   - 远端宽峰 → 增强子活性
   - 基因体区域峰 → 基因可能正在转录
   ```

#### **实际解读案例：**

```text
细胞类型A:
    ████      TSS区域有明显峰 → 基因A活跃
    ████      
    ████      
    __________
    基因A

细胞类型B:
      ██       TSS区域峰较低 → 基因A沉默
      ██
      ██
    __________
    基因A

结论：基因A在细胞类型A中特异表达
```

### 4. 综合分析示例

```r
# 使用Signac/R进行可视化
library(Signac)
library(Seurat)

# 查看特定基因区域的覆盖度
CoveragePlot(
  object = pbmc_atac,
  region = "MS4A1",  # B细胞标记基因
  features = "MS4A1",
  assay = 'peaks'
)

# 输出解读：
# 1. B细胞群 → TSS区域有明显峰
# 2. T细胞群 → 无明显峰
# 3. 结论：MS4A1是B细胞特异性基因
```

### 5. 质控指标参考

| 指标 | 正常范围 | 含义 |
|------|----------|------|
| **FRiP** | >15-20% | 信号富集程度 |
| **TSS enrichment** | >4-6 | 启动子区域富集 |
| **Fragment length distribution** | 核小体带型 | 染色质开放性 |
| **Peak number per cell** | 1000-10000 | 细胞活性 |

### 总结

- **fragment**：原始数据单位
- **peak**：分析单元（特征）
- **fraction**：质量控制指标
- **call peaks**：将连续信号转为离散特征
- **coverage plot**：可视化验证生物学发现
