| **调试与运行** | ❌ 不支持 | 需外部命令行 | 内置调试器、集成终端 | 继承VS Code，AI可协助定位错误 | 继承VS Code，AI可精准定位错误行 |
| **版本控制** | ❌ 不支持 | 需外部Git工具 | 内置Git可视化面板 | 继承VS Code | 继承VS Code |
| **资源占用** | 极轻量 | 轻量 | 中等偏重 | 与VS Code相当 | 与VS Code相当 |

| **适用场景** | 临时查看代码 | 轻量脚本编辑、低配电脑 | 专业软件开发、多语言项目 | AI驱动的高效开发 | 国产AI编程、企业本地化需求 |
